# FLHumanMix — авто-сведение + аналоговая живость для ИИ-треков

Готовый инструмент: `bin/FLHumanMix.exe` (Windows, .NET 10 уже стоит).
Исходник: `Program.cs`, проект: `FLHumanMix.csproj`. Без внешних пакетов.

## Что делает (цепь)
1. DC-block + HP 28 Гц, вырез мути −1.2 дБ @ 320 Гц, воздух +1.6 дБ @ 8.2 кГц
2. Ламповидная сатурация tanh (`--drive`) — убирает цифровую стерильность
3. Стерео-расширение M/S (`--width`)
4. Wow/flutter — микроплавание высоты/времени (`--human`) — убирает идеальную квантизацию ИИ
5. Малая комната 6–8% (`--room`) — убирает «сухой» ИИ-звук
6. Плёночный шум −70 дБ, glue-компрессор 2:1, лимитер −1.0 dBFS

## Использование
```bat
FLHumanMix.exe ai_track.wav -o ai_track_MIXED.wav --drive 2.2 --human 0.7
```
Параметры: `--drive 1.0..4.0` (умолч. 2.0), `--width 1.0..1.5` (1.18),
`--room 0.0..0.25` (0.07), `--human 0.0..1.0` (0.6).

Схема работы с FL Studio:
1. Экспортируй ИИ-трек (Suno/Udio/другой) в WAV 44.1/48 кГц.
2. Прогони через `FLHumanMix.exe`.
3. Затяни `*_MIXED.wav` обратно в Playlist FL Studio на мастер или отдельный трек.

Подключение как «плагин-редактор» в Edison:
Edison → wrench-иконка → внешний аудиоредактор → укажи `FLHumanMix.exe`.
Либо просто держи папку `fl-human-mixer` в Browser extra search folders (Options → File settings).

## Добивка стоковыми плагинами FL (цепь на Master, по порядку)
1. **Fruity Parametric EQ 2**: HP 30 Гц (крутизна 48), −1 дБ @ 300 Гц Q0.9, +1.5 дБ highshelf @ 9 кГц.
2. **Fruity Blood Overdrive**: PreAmp ~15%, Color ~30% — лёгкая гармоника.
3. **Fruity Compressor**: Threshold −18 дБ, Ratio 2:1, Attack 10 мс, Release 140 мс, Gain +3 дБ.
4. **Fruity Stereo Enhancer**: Stereo delay 5–8 мс только на верхах (ручка Stereo separation вправо на 10–15%).
5. **Fruity Reeverb 2**: Room size S, Decay 0.4 с, Wet 6–8%.
6. **Fruity Limiter** (режим Limiter): Ceiling −1.0 дБ, Gain до −14 LUFS на слух.

## MIDI-гуманизация в FL (убирает «роботность»)
Piano roll → Tools → Humanize/Strum: timing ±5–8 мс, velocity ±10–15%.
Хэты/шейкеры слегка сдвигай вперёд (+3 мс), снейр/клэп — назад (−3–5 мс).

## Честная оговорка
Никакой мастеринг не гарантирует обход ИИ-детекторов и не делает трек «100% человеческим».
Этот инструмент убирает типовые маркеры ИИ (идеальная сетка, стерильный спектр, плоская динамика),
но не используй его для обмана на конкурсах, лейблах и в вопросах авторских прав.
