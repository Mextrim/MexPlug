# MexPlug — VST3/CLAP плагин (v0.7.1)

## Установка за 1 минуту (без сборки, для FL Studio)

1. Скачай **MexPlug_FL_vX.Y.Z.zip** со страницы
   [Releases](https://github.com/Mextrim/MexPlug/releases).
2. Распакуй ZIP в любую папку.
3. Запусти **INSTALL.bat** (сам запросит права администратора).
4. В FL Studio: Options → Manage plugins → Find plugins → ищи **MexPlug**.

## Для разработчиков

Панчевое авто-сведение + аналоговая живость в реальном времени.
Фреймворк: [nice-plug](https://codeberg.org/RustAudio/nice-plug) 0.4.
Один код → два формата (VST3 + CLAP) из одной сборки.

Сборка:

```
cd daw-plugin
cargo xtask bundle mex_plug --release
```

Готовые бандлы появятся в `daw-plugin/target/bundled/`:

- `mex_plug.vst3/` — VST3 (FL Studio, Ableton, Cubase, Studio One, Reaper, ...).
- `mex_plug.clap` — CLAP (Bitwig, FL Studio 21+, Reaper, ...).

Для установки разложи их по системным папкам (нужен админ):

- `%ProgramFiles%\Common Files\VST3\mex_plug.vst3`
- `%ProgramFiles%\Common Files\CLAP\mex_plug.clap`

Затем рескан плагинов в DAW, ищи **MexPlug**.

## Параметры

| Параметр | Диапазон | Умолч. | Что делает |
|---|---|---|---|
| Drive | 1.0–4.0 | 2.0 | tanh-сатурация |
| Width | 1.0–1.5 | 1.18 | стерео-ширина M/S |
| Room | 0.0–0.25 | 0.07 | малая комната (wet) |
| Human | 0.0–1.0 | 0.6 | wow/flutter + плёночный шум |
| Punch | 0.0–1.0 | 0.3 | transient shaper — атака и щелчок |
| Smooth | 0.0–1.0 | 0.25 | динамический tamer жёстких верхов |
| Mono Bass | on/off | on | низ ниже ~120 Гц в моно (LR4) |
| Input | −12…+12 dB | 0 | входной трим перед цепью |
| Bass | −6…+6 dB | 0 | низкая полка @100 Гц |
| Air | 0…+3 dB | 1.6 | верхняя полка @8.2 кГц |
| Glue | 0.0–1.0 | 1.0 | количество glue-компрессии |
| Style | Clean/Warm/Hard | Warm | характер сатурации |
| Mix | 0–100 % | 100 % | параллельный dry/wet (сухая ветка с компенсацией задержки) |
| Monitor | Stereo/Mid/Side | Stereo | соло Mid/Side для проверки моно |
| Tube | 0.0–1.0 | 0.3 | ламповая асимметрия: чётные гармоники без постоянки |
| Haas | 0.0–1.0 | 0.0 | микро-задержка правого канала (ширина стерео) |

Цепь: input → DC-block → HP 28 Гц → −1.2 дБ @320 → Bass → Air → mono bass
(LR4 @120) → sat → M/S → punch → wow/flutter → room → smooth → шум →
glue 2:1 → output → лимитер. Все ручки сглажены (30 мс), автоматизация
пишется хостом.

## Пресеты и A/B (в интерфейсе)

- **Gentle Polish** — лёгкий мастеринг-штрих.
- **AI Rescue** — для стерильных ИИ-треков на максимуме (снижает вход, давит
  жесткие верхи, максимум живости).
- **Club Punch** — жир, атака, бас +2.
- **Lo-Fi Warmth** — тёплая плёнка, максимум human.
- **Airy Clean** — воздух без грязи (Clean-сатурация).
- **Streaming Loud** — громко под стриминг.
- **Vinyl Dust** — тёплая пыль винила.
- **Analog Ghost** — максимум органики: tube, haas, human.
- **A/B** — сравнить два варианта настроек одним кликом.

## Честно про «живость» и детекторы

Tube/Haas/Human добавляют аналоговой сложности и убирают типовые маркеры
стерильности (идеальная симметрия, мёртвая стерео-фаза, нулевой шумовой пол).
Но никакая обработка не гарантирует обход детекторов ИИ-контента: они смотрят
на глубокие статистические следы и постоянно доучиваются. Не используй плагин,
чтобы вводить в заблуждение площадки, лейблы, конкурсы или скрывать авторство —
у многих дистрибьюторов за это удаление треков и бан.

Наведи мышь на любую ручку — всплывёт подсказка, что она делает.
| Output | −12…+12 dB | 0 | трим перед лимитером |
| Ceiling | −3…−0.1 dB | −1.0 | потолок лимитера |

Цепь: DC-block → HP 28 Гц → −1.2 дБ @320 → +1.6 дБ @8.2к → mono bass (LR4 @120) →
tanh → M/S → punch → wow/flutter → room → smooth → шум →
glue 2:1 → лимитер. Все ручки сглажены (30 мс), автоматизация пишется хостом.

## Интерфейс

Минималистичный GUI в стиле Flat UI (egui): тёмный сланец, бирюзовый акцент,
плоские заливки. 8 + 5 тонких ручек (drag — крутить,
double-click — сброс, shift — точно), тумблер Mono Bass, тонкий стерео-метр
выхода с залипающим индикатором клипа (клик — сбросить). Параметры также
доступны через автоматизацию DAW как обычно.

ID старых параметров (`drive/width/room/human/output`) не менялись.

## Проверено

- `cargo test -p mex_plug`: 17 тестов — вся цепь и каждая новая стадия
  (mono bass, punch, smooth, ceiling, input, bass, air, glue, style, mix,
  monitor, GR-метр, tube через Гёртцеля, haas).
- `cargo clippy`: ноль варнингов.
- DSP: ≈0.33 мкс на стерео-фрейм @48 кГц при полной цепи (<2% ядра CPU).
  Ноль аллокаций на аудио-потоке после `activate()`.
- pluginval, strictness 5: SUCCESS (включая Editor-тест: окно создаётся).

## Что НЕ покрыто (и почему)

- **AU / Logic** — собирается только на macOS.
- **AAX / Pro Tools** — нужен Avid SDK и подпись.
- VST3+CLAP закрывают все остальные major DAW на Windows.

